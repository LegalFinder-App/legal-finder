# Phase 6 — Silicon Valley Counsellor / RAG UI

Dedicated craft pass on Counsellor: citation hover, grounded trust pills, streaming motion,
research keyboard, and responsive density — ink/brass LegalFinder, not purple glass.

## Delivered

### Citations
- Inline chips open a **hover preview** (authority, title, court/date) then click → full sheet
- `counsellor-cite-pop` mount animation (reduced-motion safe)

### Streaming & trust
- Thinking indicator: pulse ring + progress bar driven by real status labels
- **Grounded** / **General guidance** pill on finished assistant turns
- Source rail shimmer while retrieving; staggered card rise-in

### Research workbench
- ↑↓ / Enter keyboard navigation on results (when focus isn’t in an input)
- Zero-result suggested queries
- Horizontal filter chips on phones; stacked search button

### Responsive shell
- Tighter phone margins; wider research pane on `xl`
- Touch-friendly composer + full-width citation sheet actions (Phase 5)

## Docs chain

Phases 0–5 cover registry → FTS → feed cites → statute chunking → senior counsel → ops/trust.
This phase is the explicit UI deliverable from the approved RAG + SV UX plan.

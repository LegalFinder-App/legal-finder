# iOS native project

Generated by Capacitor (`npx cap add ios`, run from `platforms/mobile/`) — a real Xcode project.
**This cannot be built, run, or verified on Windows/Linux — Xcode is macOS-only, full stop.**
Everything below needs a Mac, or use `.github/workflows/mobile-ios-build.yml` (GitHub's hosted
macOS runners) if you don't have one.

## On a Mac, one-time setup

```
brew install cocoapods   # if not already installed
cd platforms/mobile/ios/App
pod install
```

## Build & run

```
npm run mobile:sync        # from the repo root, after any capacitor.config.ts or icon change
npm run mobile:ios:open    # opens ios/App/App.xcworkspace in Xcode
```
**Open `App.xcworkspace`, not `App.xcodeproj`** — CocoaPods dependencies only resolve through the
workspace. From Xcode: pick a simulator or connected device, hit Run.

## App Store submission

1. Join the Apple Developer Program (separate from a free Apple ID — $99/yr, required for
   any App Store distribution).
2. In Xcode: Signing & Capabilities tab, select your team, let Xcode manage the provisioning
   profile (simplest) or create one manually in the Apple Developer portal.
3. Product > Archive, then use the Organizer window's "Distribute App" flow to upload to App
   Store Connect (or export an `.ipa` and upload via Transporter).
4. Create the app listing in App Store Connect: screenshots per required device size, privacy
   policy URL, App Privacy "nutrition label" — see `../README.md`'s store checklist for what this
   app specifically touches (auth, messaging, payments).

See `.github/workflows/mobile-ios-build.yml` for a CI path that automates the build step (not the
App Store Connect upload, which still needs your Apple credentials as repo secrets).

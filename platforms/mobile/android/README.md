# Android native project

Generated by Capacitor (`npx cap add android`, run from `platforms/mobile/`) — this is a real
Gradle/Android Studio project, not a template. Don't hand-edit generated files under `app/src/main/assets/`
(`capacitor.config.json`, the `public/` web assets folder) — those are overwritten by `npx cap sync`.

## Build

```
npm run mobile:sync            # after any capacitor.config.ts or icon change
npm run mobile:android:build   # headless debug APK via Gradle
```
APK output: `app/build/outputs/apk/debug/app-debug.apk`. Install on a connected device/emulator
with `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

Or open in Android Studio for the full IDE experience (emulator management, Logcat, etc.):
```
npm run mobile:android:open
```

## Release signing (Play Store)

1. Generate a keystore (one-time, keep it safe — losing it means you can never update the app
   under the same listing): `keytool -genkey -v -keystore legalfinder-release.keystore -alias legalfinder -keyalg RSA -keysize 2048 -validity 10000`
2. Add signing config to `app/build.gradle`'s `signingConfigs`/`buildTypes.release` blocks (Android
   Studio's Build > Generate Signed Bundle/APK wizard can do this for you interactively).
3. Build a release AAB (Play Store's required format, not APK): `./gradlew bundleRelease`, output
   at `app/build/outputs/bundle/release/app-release.aab`.
